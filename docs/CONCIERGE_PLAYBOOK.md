# PROVENTA CONCIERGE OPERATIONS PLAYBOOK
**Edition**: Wave 1 Launch — Ahmedabad, Gujarat, India  
**Brand Statement**: *Life, Handled.*

---

## 1. Core Operating Principles

1. **Absolute Truth & Verification**:
   - Never fabricate a booking reference, seat availability, or venue policy.
   - A booking is ONLY marked `CONFIRMED` when a real confirmation reference from the provider is in hand.
   - If a venue is fully committed, present verified alternatives immediately with discretion.

2. **The Ownership Rule**:
   - Every active request has exactly ONE assigned concierge.
   - No orphaned requests in the queue.
   - If an agent is ending a shift, all uncompleted requests must be formally handed off to the incoming concierge.

3. **Customer Transparency**:
   - Any financial commitment or booking with cancellation penalties requires an explicit Customer Approval Card.
   - Never book on behalf of a customer without prior approval of price and terms.

## 2. Operational SLAs (Wave 1: Ahmedabad)

| Metric | Target | Action on Breach Warning |
|---|---|---|
| **Initial Response** | 30 Minutes | Auto-escalate to Concierge Manager |
| **Options Presented** | 2 Hours | AI Copilot research assist triggered |
| **Execution / Booking** | 4 Hours | Concierge Manager direct intervention |

Operating Shift Hours: **09:00 to 21:00 IST** (Daily).

---

## 3. Brand Voice & Communication Guide

- **Tone**: Calm, capable, understated, warm, discreet.
- **Do**:
  - Use simple, direct phrasing.
  - Acknowledge constraints and state clear next steps.
  - Address customers by name.
- **Do NOT**:
  - Use robotic filler ("As an AI...", "I hope this email finds you well").
  - Use excessive exclamation marks or emoji parades.
  - Overpromise or offer speculation.

---

## 4. Ahmedabad Provider Verification Checklist

Before presenting a provider to a customer:
1. Contact verification: Verify active phone / manager contact.
2. Timing verification: Confirm opening hours, dress codes, and reservation windows.
3. Special dietary checks: Note Jain / Swaminarayan / Pure Vegetarian accommodations.
